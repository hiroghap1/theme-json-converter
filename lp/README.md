# LP（WP theme-json Converter）

Figma プラグイン「WP theme-json Converter」のランディングページ制作用ディレクトリ。プラグイン本体のビルド（`src/` → `dist/`）とは独立しています。

## ディレクトリ

```
lp/
├── README.md            … このファイル（前提・構成・進め方）
└── wireframe/
    ├── index.html       … ワイヤーフレーム（日本語版）
    ├── en.html          … ワイヤーフレーム（英語版）
    ├── wireframe.css    … 共通スタイル
    └── wireframe.js     … 閲覧用ツールバー（言語・表示幅・注釈の切り替え）
```

`wireframe/index.html` をブラウザで直接開いて見ます。上部のツールバーで日本語 / English、PC（1200px）/ SP（375px）、注釈（付箋）の表示を切り替えられます。`?view=sp` を付けると SP 表示で開きます。

## 進め方

1. **ワイヤー**（今ここ）: 構成・情報量・コピー案を固める
2. **デザイン**: 配色・タイポグラフィ・ビジュアル。プラグイン UI の WordPress ブルー（`#0073aa`）を起点にするかを決める
3. **画像の支給**: 上記「画像リスト」
4. **実装**: 日英2ページ
5. **公開**: stella-create.co.jp/tools/ 配下に設置
