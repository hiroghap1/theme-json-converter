05 DETAIL
01 IMPORT

theme.json を読み込むだけで、
Figma にトークンが揃う

既存テーマの theme.json から、バリアブルとテキストスタイルを自動作成します。

  • ドラッグ＆ドロップで読み込み
  • カラー・デュオトーン・スペーシング・ディメンション・レイアウト幅・フォントファミリー・角丸・ビューポートをバリアブルに
  • 可変フォントサイズ（fluid）は Desktop / Mobile の2モードにテキストスタイルのフォントサイズにバインド
  • テキストシャドウ（WordPress 7.2）はエフェクトスタイルにem やパレット色の指定は説明欄に残し、エクスポートでそのまま戻す
  • 同名のバリアブルは値を更新、なければ新規作成
  • スラッグ（例: spacing--20）を保持
スクリーンショット
インポートタブ＋作成された Variables パネル
02 EXPORT

Figma のデザインシステムを、
そのまま theme.json に

出力したい設定を選んで書き出すだけ。ブロックテーマにそのまま渡せます。

  • appearanceTools・defaultPalette・textIndent・viewport など、項目ごとに出力の有無と値を設定
  • Theme Colors の追加モード（Dark など）をスタイルバリエーション styles/*.json として zip 出力
  • インポート時のスラッグに戻して出力
  • 対象 WordPress バージョンに合わせた $schema と出力項目
スクリーンショット
エクスポートタブ（オプション一覧）
theme-json.zip ├ theme.json └ styles/ └ Dark.json
出力 JSON の抜粋
03 GENERATE

スターターセットを作成

新しいテーマを始めるときの土台づくりに。WordPress のバージョンに合わせた項目を一式用意します。

  • カラーパレット・デュオトーン・フォントサイズ・レイアウト幅
  • version 2 からフォントファミリー、version 3 からスペーシングと可変フォントサイズ（Desktop / Mobile）も
  • WordPress 7.0+ で角丸・ディメンション、7.1+ でビューポート、7.2+ でテキストシャドウを追加

07 VERSIONS
COMPATIBILITY

WordPress 5.8 から 7.2 まで

theme.json の version 1〜3 に対応。エクスポートと生成では、選んだバージョンで使える設定だけを扱います。

  1. Version 1
    WordPress 5.8+
    基本のカラー・フォントサイズ
  2. Version 2
    WordPress 5.9+
    ＋ フォントファミリー
  3. Version 3
    WordPress 6.6+
    ＋ アクセントカラー・スペーシング・可変フォントサイズ
  4. Version 3
    WordPress 7.0+
    ＋ 角丸・ディメンション・textIndent
  5. Version 3
    WordPress 7.1+
    ＋ ビューポート ほか
  6. Version 3
    WordPress 7.2+
    ＋ テキストシャドウ・backgroundClip
    最新・初期値

10 FAQ
FAQ

よくある質問

料金はかかりますか？
無料でお使いいただけます。
すでにあるバリアブルは上書きされますか？
同じ名前のコレクション・バリアブルがある場合は値を更新し、ない場合は新しく作成します。
ダークモードは扱えますか？
Theme Colors コレクションの2つ目以降のモード（Dark など）を、スタイルバリエーション styles/<モード名>.json として theme.json と一緒に zip で書き出します（Version 3 を選んだとき）。
どの WordPress バージョンに対応していますか？
theme.json の version 1〜3（WordPress 5.8〜7.2）に対応しています。
vw や em で指定したフォントサイズは読み込めますか？
フォントサイズは px と rem に対応しています。読み込めなかった項目は完了時の通知に表示されます。
FigJam や Dev Mode でも使えますか？
Figma のデザインファイルで動作します。FigJam・Dev Mode には対応していません。
英語でも使えますか？
はい。プラグインの画面は日本語と英語に対応しています。ヘッダーで切り替えられ、選んだ言語は次回以降も保持されます。
