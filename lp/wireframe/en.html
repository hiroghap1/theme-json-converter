05 DETAIL
01 IMPORT

Load a theme.json,
get your tokens in Figma

Create variables and text styles automatically from an existing theme's theme.json.

  • Drag and drop to import
  • Colors, duotone, spacing, dimensions, layout widths, font families, border radius and viewport become variables
  • Fluid font sizes get Desktop / Mobile modesBound to each text style's font size
  • Text shadows (WordPress 7.2) become effect stylesem units and palette colors are kept in the description and exported as is
  • Variables with the same name are updated; others are created
  • Slugs (e.g. spacing--20) are preserved

02 EXPORT

Ship your Figma design system
as theme.json

Pick the settings you need and export — ready to drop into your block theme.

  • Include or exclude each setting — appearanceTools, defaultPalette, textIndent, viewport and more — and set its value
  • Extra modes of Theme Colors (e.g. Dark) are exported as style variations, styles/*.json, in a zip
  • Original slugs are restored on export
  • $schema and exported settings match your target WordPress version

10 FAQ
FAQ

Frequently asked questions

Is it free?
Yes. The plugin is free to use.
Will it overwrite my existing variables?
If a collection and variable with the same name already exist, their values are updated. Otherwise, new ones are created.
Does it support dark mode?
Extra modes in the Theme Colors collection (e.g. Dark) are exported as style variations, styles/<mode>.json, zipped together with theme.json (when you choose Version 3).
Which WordPress versions are supported?
theme.json versions 1–3 (WordPress 5.8–7.2).
Can it import font sizes set in vw or em?
Font sizes in px and rem are supported. Anything that can't be imported is listed in the notification when the import finishes.
Does it work in FigJam or Dev Mode?
It works in Figma design files. FigJam and Dev Mode are not supported.
Is the plugin available in English?
Yes. The plugin UI is available in English and Japanese. Switch it from the header, and your choice is remembered.
